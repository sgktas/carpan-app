# Product reviewer guide

Scope updated 13 October 2026. [Current readiness](grant-readiness-2026-10-13.md) records dated verification and remaining work.

Start at **https://carpan.app/about?lang=en**.

1. Read the product overview and historical USDC collection journey. Finance now also includes private business movement operations; the web platform is separate from Çarpan Muhasebe Asistanı, the Turkish desktop accounting product.
2. Open [real Arc blocks](https://carpan.app/arc?view=explorer&data=blocks&lang=en). Select a block and its evidence/transactions. No account or wallet required.
3. Open [Finance wallet research](https://carpan.app/finance?view=research&lang=en). Choose a public Arc address explicitly. RPC balance and loaded-range metrics identify their sources and freshness; an empty bounded page does not establish an empty historical wallet.
4. Inspect [business operations](https://carpan.app/finance?view=operations&lang=en) with your own Google, email or wallet account. Connection alone is not authentication. Opening Finance does not create company records; workspace creation is an explicit action. Existing company workspaces, eligible business wallets, private counterparties and decisions persist per workspace. A new account starts empty.
5. For an operations demonstration, deliberately create your own workspace and register an eligible wallet, then load a bounded block window, discover historical receipts or import a known transaction hash. Inspect canonical native USDC evidence and its ERC-20 aliases, separate gas, source failures and partial coverage. Review/classification/reference/approval produce saved decisions; immutable JSON batches preserve the reviewed versions. The file is `readyForPosting:false` / `accountingStatus:not_submitted`, with no automatic ERP posting. [Operation scope](carpan-finance-operations-2026-10-12.md) · [History limits](carpan-finance-history-api-budget-2026-10-12.md). The isolated tests are an alternative to creating review records.
6. Open [Collections](https://carpan.app/finance/collections?lang=en). Guest instructions explain request → public link → receipt → owner matching → CSV. Creating a request changes your private workspace. Review recipient/amount/network/gas and **stop before paying** for a review without a financial action. Customer/invoice notes are private. The signed 9 October owner acceptance pilot is recorded separately in [historical evidence](live-acceptance-2026-10-09.md).
7. Open [Ecosystem](https://carpan.app/ecosystem?lang=en). Filter projects by category/status. Compare a documented Circle CCTP address with the Aave participant entry; open the sourced address in Terminal and its related-project link. Saving is private and requires the same Carpan account. Reviewed community proposals and optional referral programmes remain available.
8. Inspect [Tokens & Markets](https://carpan.app/ecosystem?view=tokens&lang=en): documented assets, Arc pools and newly indexed pools are separate views. Open a pool, switch between24hour/7day and base/quote source candlesticks, and follow exact token evidence into Terminal. Values show GeckoTerminal attribution, retrieval time and freshness; volume/liquidity are pool metrics, not global token aggregates. Missing data remain unavailable; pool identifiers are distinguished from EVM addresses. [Market scope and verification](carpan-markets-2026-10-10.md).

9. Funding/development and project updates are now implemented. Open [Upcoming](https://carpan.app/ecosystem?view=upcoming&lang=en) and compare an exact programme deadline with Extended's announced migration week. Arc Acceleration Season remains in progress but its application deadline has already passed. Open the linked project profiles for historical company funding, documented capabilities and announced roadmap plans; these do not establish Arc deployment or current valuations.
10. In a signed-in account, save a reviewed project and open My Watchlist or its profile. New-update and exact-deadline reminder preferences are independently opt-in and default off. Notifications are private and in-app only; old announcements are not replayed. Unsave stops future notifications. [Source, notification and verification scope](carpan-ecosystem-updates-2026-10-10.md).

11. Open the separate [API category](https://carpan.app/developers?lang=en). It intentionally says access is closed. Key creation, external Finance API methods and webhook delivery are unavailable; `/finance?view=integrations` redirects here. Internal Finance operations continue to work. Connector source describes implementation for a future approved launch, not current commercial access or a completed accounting-software pilot. [API closure](carpan-api-closed-2026-10-12.md).

Run `npm ci` and `npm run verify` in the clean export. Tests use isolated DBs/mocked providers and no financial signing. The public repository is [sgktas/carpan-app](https://github.com/sgktas/carpan-app); [initial hosted verification](https://github.com/sgktas/carpan-app/actions/runs/38367478454) passed 401 tests / 24,345 assertions with zero failures, plus guard/lint/frontend TypeScript/build. Historical Arc↔Arbitrum acceptance is separate from additional-route configuration checks; new-route financial pilots remain paused by the owner. Read [architecture](architecture.md), [grant brief](grant-submission.md), [current readiness](grant-readiness-2026-10-13.md) and the included [roadmap](../ROADMAP.md) for evidence and planned work. The source package includes the Finance operations, historical connector, history-repair and current API-closure reports linked above and from the roadmap.
